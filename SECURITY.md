# Security Policy

We take the security of Agent POSIX seriously. This document outlines how to report security vulnerabilities and our process for handling them.

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue. Instead, report it privately by emailing community leaders at [security@agentposix.org].

Please include as much information as possible to help us reproduce and understand the issue, such as:
- A clear description of the vulnerability.
- Steps to reproduce (including configuration and sample code).
- Any potential impact on users or storage.

Once we receive your report, we will:
- Acknowledge receipt within 48 hours.
- Work on a resolution and coordinate a public release timeline with you.

## Scope

This security policy applies to all core package code in `agentposix/` and its official storage/adapter modules.
